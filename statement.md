\# Project Statement



\## Project Title



Crime Case Analyzer



\## Problem Statement



Managing crime case information manually can make it difficult to organize, search, update, and track case records. This project provides a simple Python-based system for managing fictional crime case information in an organized way.



\## Objectives



\- To create a simple Python-based crime case management system.

\- To store case information in an organized format.

\- To provide case searching and viewing features.

\- To update and track case status.

\- To calculate case priority based on evidence count.

\- To allow deletion of unnecessary case records.

\- To practice Python functions, lists, conditional statements, file handling, and CSV storage.



\## Scope



The project is designed as an educational case-management application. It can add, view, search, update, and delete case records. It also provides simple priority analysis and case resolution tracking.



The project uses fictional data for demonstration and is not intended for real criminal investigations.



\## Target Users



\- Students learning Python

\- Beginners practicing file handling

\- Users who want to understand basic case-management systems
